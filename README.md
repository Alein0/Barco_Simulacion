Instrucciónes (Repositorio)
1. Descargar el proyecto del repositorio (aquí se encuentra todo el desarrollo del proyecto)
2. Descomprimir el proyecto
3. Abrir la carpeta del proyecto
4. Abrir la carpeta "BoatShipSimulator_Build" dentro del repositorio descargado
5. ejecutar "Pirate ship simulator"

1. Dirigirse a Releases
2. ver la ultima release subida "v1.1"

5. abrir la carpeta descomprimida "BoatShipSimulator_Build.zip"
